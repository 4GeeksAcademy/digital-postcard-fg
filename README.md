# digital-postcard-fg# Digital Postcard Project

This is a beginner-friendly digital postcard created with **HTML5** and **CSS3** as part of my 4Geeks Academy practice exercises.

## Project Description

The goal of this project was to recreate a postcard layout using basic web development concepts such as HTML structure, CSS styling, Google Fonts, images, form inputs, spacing, margins, padding, and layout organization.

The postcard includes:

* A custom postcard container
* A header with title and logo
* A message section
* Form-style input fields
* A centered button
* External CSS styling
* Google Fonts integration

## Technologies Used

* HTML5
* CSS3
* Google Fonts
